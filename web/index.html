    Regras do Estudo Diário

    Você tem uma sessão de estudo por dia.

    • Um assunto aleatório da Wikipédia é sorteado para você.
    • O relógio de 25 minutos começa a contar.
    • Use esse tempo para pesquisar e aprender.
    • Escreva um resumo com 100 a 2.000 caracteres com suas próprias palavras.
    • Uma IA avalia seu resumo (0 a 10) e os pontos vão para o ranking.

    Regras de conduta:

    • O resumo deve ser escrito por você.
    • Não copie e cole o material.
    • Não use IA para gerar o resumo.
    • Apenas uma tentativa por dia.

    Política de Privacidade

    Coletamos o mínimo necessário para o serviço funcionar.

    • Nome: exibido no ranking.
    • E-mail: usado para login (nunca exibido publicamente).
    • Senha: salva como hash bcrypt.
    • Resumos: usados para avaliação e histórico.

    Seus dados são enviados para a API da OpenAI com store: false, garantindo que não sejam usados para treino.

    O token de acesso é salvo apenas no localStorage do seu navegador.

    ⭐ Projeto Open Source e Gratuito

    🤝 Confiamos na comunidade — trapacear é se enganar, não nos enganar. O uso de IA para gerar conteúdo é contra as regras do jogo.
